## 2. 已知缺陷 / 未验证（对外不得写"已验证"）

- **大知识库性能（已知限制，不作发布阻塞）**：CHANGELOG 0.5.1 原文——「读/写路径在知识库增长时仍是 O(历史)——50k 条证据时单次读操作数百毫秒、逐条追加呈二次增长。checkpoint 已能避免"截断丢实体"，但尚未把读路径变成增量。本版**不承诺大知识库下的性能**；下一批计划 \`evidenceKeys\` 常数时间去重与索引增量更新。」README 同步写明「知识库很大时读/写仍随历史线性增长，本版不承诺大库性能」。本次冻结版实测：50k 条 / 7.0 MB，listLessons 555ms、listEvidence 562ms、stats 539ms、面板合计 1656ms（阈值 150ms/次）；lead 另测得逐条 append 在 20k 条时已超时，确认写路径二次增长。
- **真实宿主目视**：第 8 项的 18 张截图是离线夹具渲染，不能替代真实宿主 Web/Desktop 的目视验收；该项仍 ❌。
- **18 插件同载冷启动**：未重跑，0.5.0 的欠账延续。
- **发布物安装**：未把 \`stardustlc-dsh-dream-0.5.1.tgz\` 装进干净 profile 跑端到端；未从 registry 重装冒烟。
- **真实用户日记**：所有自动测试只用合成夹具；真实 \`dreams.jsonl\` 未参与任何 CI。
