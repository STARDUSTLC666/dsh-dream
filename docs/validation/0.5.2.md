# dsh-dream 0.5.2 发布证据包（面板折叠断点修复）

> 范围：仅 `lib/client.js` 一处 CSS 级联修复；**不含 M2 面板改动**。
> 基线：0.5.1（`3a90ff7` / tag `v0.5.1`）。复跑时间：2026-09-29（Asia/Shanghai），Node v24.16.0。

## 1. 修复

- **现象**：≤620px 窄窗下 `.dshd-toolbar .dshd-hint` 已按容器查询隐藏，但 `.dshd-two` 仍是两列；1024px 视口 + 150% 缩放同理（hint 已隐藏、grid 未折叠）。
- **根因**：`@container (max-width:620px){.dshd-two{grid-template-columns:1fr}}` 排在基础 `.dshd-two{grid-template-columns:minmax(0,3fr) minmax(0,2fr)}` 之前，同特异性被后者级联覆盖。
- **修复**：把该 `@container` 块整体移到 CSS 数组末尾（`lib/client.js`，2 行移动 + 补逗号，无其他改动）。

## 2. 折叠断点语义（本版明确）

**折叠断点 = 容器内容宽 ≤620px（`@container`，非视口 media query）。** 因此 1024px 视口 + **150% 缩放**时，面板容器 content-box ≈617px，会折叠为单列——**属预期**；125% 缩放下容器 ≈754px，仍两列。窄窗（视口 620px，容器 content-box 554px）折叠为单列。缩放、窄窗、面板被挤窄共用同一条规则。
