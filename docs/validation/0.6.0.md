# dsh-dream 0.6.0 验收记录

日期：2026-09-30（Asia/Shanghai）。基线：0.5.2（2e91377）。
本页记录源码与隔离环境验收；GitHub CI 和 npm 发布结果由发布流程另行核对。

## 已修复

- 模型自报 read、伪造用户纠正可直接提升经验：改为实际核对来源，新经验留在候选，审阅记录不冒充用户。
- web 脱敏破坏 UUID：保留经过校验的内部引用，正文、密钥赋值与敏感串继续脱敏。
- Linux 目标路径被当成长令牌，导致回滚命令失效：结构化绝对路径按目录分段脱敏，正常路径完整保留，路径中的密钥继续打码。
- attach-evidence 声明可用但无实现：补充真实来源、检查 revision，保持经验状态。
- 冲突组逐条修改可能半成功：完整校验后在一个事件中更新，其他未解决冲突继续扣留。
- 新建文件的预览哈希为 null 但 apply 不接受：公共 schema 与执行流程均支持 null。
- 目标先写、恢复记录后写：先 fsync pending 记录，再原子替换；进程中断后仍能找到备份并回滚。
- Windows 项目收到 Linux 平台经验：显式平台优先，其次明确任务文字，再采用宿主平台。
- 回滚按钮在实际面板缺失：修复真实记录投影与命令生成的字段衔接。
- 面板重复显示待核实条目、行动建议隐藏、冲突命令缺少参数、Escape 误关设置：拆分视图并提供完整表单、命令及窄窗布局。

## 实际浏览器操作

宿主：官方源码构建的 Harness 0.2.0-rc.1（407e65c8，含本地宿主修补），Node 24.16.0。
使用真实设置页与实际插件，隔离 profile 内放置 12 条合成日记、7 条合成经验和一个项目 AGENTS.md；不读取个人历史或密钥。

| 操作 | 实际结果 |
| :-- | :-- |
| 日记 / 经验 / 写入记录切换 | 独立视图，可用与待核实条目不重复 |
| 筛选“存疑”后 Escape | 4 条日记；只关闭筛选，设置页保留 |
| 清空筛选、长文展开 / 收起 | 恢复列表，正文完整展开后可收起 |
| 搜索 SMTP | 6 条匹配日记 |
| 选择冲突经验、填写依据、复制命令 | 显示经验标题与完整参数，复制有反馈 |
| 执行界面生成的冲突命令并刷新 | 一方 usable、一方 rejected，待核实队列减少 |
| 驳回历史重新送审并刷新 | 转为 candidate 并进入待核实队列 |
| 备份标识与复制回滚命令 | 编号完整，命令可执行 |
| 回滚后核对文件并刷新 | 原人工规则及后来追加内容保留；显示不可再次回滚 |
| 1280 与 620 像素、浅色与深色 | 实际截图目视，窄窗单列，设置弹窗无横向溢出 |

界面命令由公开工具在同一隔离资料上执行；本轮未调用真实模型对话。
浏览器验收不能替代原生 Desktop 安装器验收。宿主热重载期间出现过 session-controller 服务暂不可用日志，未发现 Dream 模块激活或 React 渲染失败。

## 仍有范围限制

- 大知识库读写仍随历史增长，本轮未解决增量索引与规模性能。
- 当前来源校验读取 v0–v4 会话文件；有可见 seq、匹配原文与明确项目的记录才计为 read，不能核对时降为 claimed。
- global 桥接要求 review.decision accepted；当前工具的 actor 是 model，不据此声称真实用户已经确认。
- 未复测原生安装器、125%/150%系统缩放或模型长期行为质量。
