# Dream 0.7.0 验收范围

环境：Windows、Node 24.16.0、官方 Harness 0.2.0-rc.2（639ed015），独立 DSH_HOME 与合成资料，无用户密钥或真实会话。

浏览器实际操作已完成：展开来源和核验说明、采纳候选、记录有用及不适用场景、标记待复核后重新采纳、填写冲突依据、处理冲突、查看规则差异、应用并从写入记录确认回滚。刷新后反馈与审阅状态保持。通过另一个写者模拟旧版本操作：按钮拒绝写入，填写中的依据保留。

窄窗口检查采用 390×844 视口。发现宿主左侧导航挤压内容后，为当前 Dream 设置页增加顶部横向导航，正常窗口和其他设置页不受该媒体规则影响。实际截图保存在此次工作区验收目录。

自动回归覆盖旧接口与日志读取、人工/模型 actor 分离、反馈不自动晋级和请求幂等、并发版本冲突、关联文件修改拒绝、预览绑定与回滚保留手工内容、跨源/简单请求/大请求/取消拒绝。新写操作只注册在官方认证 Connection 通道，没有未认证的 webServer 回退路由。

范围限制：此记录证明真实 Web 宿主的可见操作与 Windows 文件行为；尚不能替代原生桌面窗口完整操作或真实用户会话核验。没有项目目录的全局经验仍需在对应项目对话中预览规则。预览按所选经验重建整个 Dream 管理块，用户应核对删除与新增差异。外部修改管理块后不强行回滚。
