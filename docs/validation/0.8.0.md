- 两个官方完整 Web 宿主使用独立 DSH_HOME、项目和 profile，保留原用户资料与凭据。通过正式 AgentRegistry 创建真人根会话，由正式 AgentLoop 调用两次只读验证工具并正常收尾；用户消息不包含「做梦/复盘」等触发词。两边均产生一条 `candidate/unreviewed` 经验，实际来源序号为 8，来源哈希由插件计算，未调用日记或规则工具。

- 中英文设置文案与状态可见；中文经验正文在英文宿主中保留。390px 宽度下导航横向滚动、正文正常换行、开关可操作，文档宽度为 390px，没有横向溢出。热重载后调用次数与开关保留，预算恢复显示默认 10 分钟，未重做已处理轮次。
- RC2 / alpha 各自的 18 插件同载契约检查：110 工具、35 技能、19 项输出夹具全部通过。没有新增运行时依赖。

## 验收边界

完整宿主流程使用注册到官方 LLM 服务的脚本 adapter，验证事件、调度、取消、来源和请求组装；不代表真实 DeepSeek 模型的候选质量或服务可达性已通过本版验收。模型可以返回空结果，或因来源不匹配而丢弃建议。

浏览器验收不等同于原生 Desktop 安装器及窗口实测。桌面共用宿主服务、插件与前端模块身份，但本版没有操作用户的前台桌面窗口。已有旧日记不迁移、不重写。

自动候选需要人工采纳；自动取回仅用 accepted/usable 且有独立来源的经验，最多三条，包含边界说明的总字符数不超过 3000。版本限定经验在依赖版本未知时扣留，显式工具仍可提供包名/版本检索。辅助请求按尝试扣预算，取消/失败不返还，也不会以「成功」重复执行。

Windows 本地完整宿主报告、截图、测试日志和包验收保存在工作区 `.harness-validation/dream-auto-20261003/`。CI、npm 发布与公开安装验收以对应工作流和公开 registry 结果为准。
